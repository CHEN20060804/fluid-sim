# 流体墨客

本程序是一个基于SPH（Smoothed Particle  Hydrodynamics）和PBF（Position-Based Fluids）方法的二维流体模拟器，系统通过粒子离散化方式模拟连续介质的动力学行为。  



## 程序特色

- **使用CUDA加速**：在 PBF 模式下部分计算通过 GPU 并行处理，加快求解速度。

- **键鼠交互设计**：模拟中支持粒子拖拽、风力作用等交互操作，增强使用体验。

- **双缓冲绘制机制**：确保画面流畅、避免撕裂和闪烁。

- **空间哈希加速**：用于快速邻域查询，提升模拟效率。

  

## 程序构建

C++版本：C++17及以上

CUDA版本：CUDA12.6及以上

IDE： Visual  Studio 2022

为正常进行PBF模拟，请使用支持 CUDA 的显卡，并尽量避免后台程序占用大量显存和线程资源。推荐在 Release 模式下运行。



## 程序使用

### 模拟模式说明

程序启动后，用户可选择使用 **SPH** 或 **PBF** 模式进行流体模拟：

- **SPH（Smoothed Particle Hydrodynamics）**：基于密度核函数估计和物理力积分，强调真实物理模拟。
- **PBF（Position-Based Fluids）**：基于约束求解方法的稳定高效模拟，更适合实时交互和大规模粒子系统。

### 正式模拟前

请前往 [设置] 或 按程序内的指引 将终端修改为 [Windows控制台主机]。

同时，为了达到最佳显示效果，建议屏幕分辨率调整为2560*1600，其他分辨率可能显示异常。

### 模拟开始后

1  按住 [左Alt键] 开启左下角吹风
2  按住 [右Alt键] 开启中部吹风机
3  按住 [空格] 键开启右下角吹风机
4  按住 [鼠标左键] 吸引粒子
5  按住 [鼠标右键] 排斥粒子
